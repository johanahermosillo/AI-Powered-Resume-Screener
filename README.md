🤖 AI-Powered Resume Screener
An intelligent web application that automates resume screening using Natural Language Processing (NLP), achieving over 90% keyword detection accuracy and reducing manual review time by 70%.

📌 Overview
This Flask-based tool helps recruiters and hiring managers quickly assess resumes by:
Scanning resumes for relevant technical keywords.
Providing real-time scoring.
Offering personalized feedback based on 150+ predefined technical skills.
Built with a focus on usability and speed, it features a responsive HTML/CSS front-end and accurate backend logic driven by Pandas and NLP tools.

🛠️ Features
📄 Batch Resume Analysis: Upload and evaluate 100+ resumes.
🧠 NLP-Based Keyword Matching: Over 90% accurate detection.
⚡ Real-Time Scoring & Feedback: Personalized, instant analysis per resume.
🎨 Responsive UI: Clean interface for better user experience on desktop or mobile.
📉 Efficiency Gains: Reduces manual resume screening by up to 70%.

📂 Tech Stack
Backend: Flask, Pandas, Python NLP libraries (e.g., NLTK or spaCy)
Frontend: HTML5, CSS3, JavaScript
Others: JSON, CSV (for skill datasets), Bootstrap (if used for styling)
